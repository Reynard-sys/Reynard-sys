<h2 align="center">About</h2>

I build product-oriented engineering systems across full-stack web, Flutter mobile, AI-assisted workflows, Web3 smart contracts, computer vision pipelines, and database-backed applications.

My repositories show a practical engineering pattern: extracting structured data from PDFs with Gemini, turning accessibility evidence into civic workflows, preserving anonymity in mental health support, building wallet-connected game systems, creating safe cybersecurity simulators, and converting image analysis into usable editor experiences.

I care about software that is usable, maintainable, and explicit about tradeoffs. The strongest through-line across my work is readable product flow, role-aware UX, validation before writes, safe local simulation modes, and documentation that separates what is fully wired from what is scoped for later phases.
